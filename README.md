# Spark Brow · Air Edition

Built to match Opera Air's floating frosted-glass UI with **SparkOS 12.7** as the homepage & new-tab experience:
- **Floating Air UI:** Frosted left rail + floating top omnibar & tab bar with behind-window macOS blur.
- **Soundscapes (Boosts):** Built-in Hyperfocus 40Hz, Spring Rain, Sea Waves, and Deep Relax 10Hz audio.
- **Take a Break:** Guided Box Breathing exercise with animated ring and 45-minute break reminders.
- **Built-in Ad Blocker & Custom App Icon:** Compiled natively on GitHub Actions (`macos-latest`).
