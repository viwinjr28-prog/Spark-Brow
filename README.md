# Spark Brow (macOS Liquid Glass Browser)

Built to compile into `Spark-Brow.dmg` automatically on GitHub Actions (`macos-latest`) — no Xcode needed on your Mac.

## How to get your `.dmg`
1. Create a new repository on GitHub (e.g. `Spark-Brow`).
2. Unzip `spark_brow_github.zip` and upload all files inside (including the `.github/workflows/build-dmg.yml` folder) to your GitHub repo.
3. Open the **Actions** tab on GitHub and click **Build Spark Brow DMG** (it runs automatically on push, or click **Run workflow**).
4. Once finished, download **Spark-Brow-DMG** from the **Artifacts** section at the bottom of the workflow run!
